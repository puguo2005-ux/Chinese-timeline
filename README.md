# 华夏纪年

一条可以拖动、检索与漫游的中国历史长河。单页网站，收录从三皇五帝到辛亥革命的时代、王朝、帝王、人物与大事。

- 时间范围：前 3000 — 1912
- 内容规模：24 个时代段、106 个政权、371 位帝王与执政者、125 位人物、373 件大事
- 技术形态：原生 HTML / CSS / JavaScript，无构建步骤、无外部依赖
- 视觉主题：以“山河长卷”为骨架，使用纸感底色、墨色文字、朱砂与青绿点缀；加入时代剪影、可逐年定位的历史疆域快照和低开销滚动动效，支持明暗双主题与减少动态偏好

## 打开方式

直接双击 `index.html` 即可。所有数据内嵌于 `data.js`，页面不依赖网络请求，`file://` 下也能正常浏览。

如需以本地服务器方式预览（推荐，便于测试深链与完整加载行为）：

```bash
cd 中国历史年表
python -m http.server 8765 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8765/>。

推荐使用较新的 Chrome、Edge、Firefox 或 Safari。

## 四个视图

| 视图 | 地址 | 说明 |
| --- | --- | --- |
| 长河 | `#/` | 首屏、全史时间轴、选定年份的天下形势与年度快照 |
| 纪年 | `#/year/755` | 输入年份，查看该年的朝代、在位者、并立政权与大事 |
| 朝代 | `#/periods` | 按时代筛选 24 段历史；点开可看帝王、大事、人物与并立政权时间泳道 |
| 大事 | `#/events` | 按类型、时代筛选或搜索 373 件大事；世纪索引、时间条与列表滚动同步 |

朝代详情与纪年页中的“山河图”已改为有来源的历史疆域快照，覆盖公元前 403 年至 1912 年。地图数据由 [jiangshan-map（江山时序）](https://github.com/DeanChensj/jiangshan-map) 的 CHGIS/Hartwell 历史地理数据整理生成，海陆底图采用 Natural Earth。历史边界仍属于概括性示意，不等同于现代测绘边界；前 403 年以前的传说与早期王朝阶段不绘制推测边界。

地图数据、生成方式、许可证与再分发限制见 `assets/maps/NOTICE.md`。分享或部署时请同时保留 `assets/maps/LICENSE-GPL-3.0.txt`。

朝代详情也有独立深链，例如唐代为 `#/period/tang`。所有地址都支持刷新与分享。

## 时间轴与自动放映

长河时间轴采用“粗调 + 精调”两层结构：

- 主时间条覆盖全史，用于快速定位；下方“精调 · 前后四十年”把当前年份前后各 40 年展开，可逐年微调。
- “仅大事 / 全部事件”切换事件密度。锚点事件保留标签；桌面端带标签的锚点使用长线，窄屏统一缩短，其余事件缩为短刻度；窄屏会自动抽样，并按屏幕宽度避让标签。
- 支持全史、千年、三百年三种缩放，双击时间轴或 `Ctrl` + 滚轮可切换。

“自动放映”支持三种范围：

- 整个历史：按章节推进全部大事，默认约 118 章。
- 一个朝代：只播放所选朝代的章节。
- 自选区间：输入起止年份，播放区间内的事件。

播放器提供慢 / 中 / 快三档速度、上一章 / 下一章、暂停、重播与重新选择范围；播放时背景年份同步更新。空格暂停，`←` / `→` 切换章节，`Esc` 退出。页面内按 `P` 也可打开放映器。

## 年份输入

纪年视图与首屏搜索框支持以下写法：

- `755`、`1911`
- `前221`、`公元前221`、`公元前221年`
- `-221`
- `221 BC`、`BC 221`
- 全角数字，如 `７５５`

内部使用天文纪年计数（前 221 年记为 `-220`），界面显示时统一转换为“前 221”。可检索范围为前 3000 年至 1912 年。

## 交互与快捷键

- **时间轴**：点击或拖动定位年份；双击切换缩放层级；`Ctrl` + 滚轮缩放；也可使用“全史 / 千年 / 三百年”分段按钮。
- **精调**：主条下方的前后四十年滑条可逐年微调，滑条两端和中间都有快捷步进按钮。
- **大事跳转**：时间轴右侧的左右箭头跳到上一件 / 下一件重要事件。
- **大事定位**：大事视图的内联时间条会跟随列表滚动更新年份；拖动时间条可直接把列表定位到对应世纪。“聚焦百年”只保留当前年份前后 50 年的事件。
- **并立政权**：朝代详情使用时间泳道展示主体、并立与周边政权在本段内的重叠关系；下方信息卡补充类型、都城、存续年与关键君主。纪年视图则以卡片列出当年并立政权。
- **移动端**：时间轴在窄屏下自动抽样事件、缩短锚点线并减少标签；纪年视图保留底部快捷年份条，朝代与大事视图使用吸顶内联时间条。
- **主题**：右上角按钮或 `T` 键切换；默认跟随系统，选择会写入 `localStorage`。也可用 URL 参数强制指定：`?theme=light`、`?theme=dark`。
- `/`：聚焦年份输入框
- `←` / `→`：年份减 / 加 1；“三百年”缩放下为 10 年；按住 `Shift` 为 50 年
- `P`：打开时光放映；空格暂停 / 继续；`←` / `→` 切换章节
- `Esc`：关闭放映器、事件抽屉或朝代详情
- 事件抽屉内会自动管理焦点，支持键盘遍历与 `Esc` 关闭

## 数据与准确性

历史内容以通行历史年表为骨架，参考中文维基百科的《中国历史年表》《中国朝代》《中国皇帝列表》《夏商周断代工程》等条目，并与《史记》《资治通鉴》等公版文献交叉校对。

- 上古与夏商周年代采用夏商周断代工程通行说法，无法确证者标注“约”。
- 帝王在位年、年号与事件年代存在异说时，取较通行的一种；部分在位时间有重叠或追尊者，按通行年表处理。
- 并立政权按年份真实重叠计算，恰好在本段结束年建立的后继王朝不计入“并立”。
- 本站是面向浏览与检索的普及性作品，不作为学术引用依据；如需严谨引用，请回到条目所依据的原始文献。

主要参考来源列于页面页脚，也可在 `data.js` 的 `sources` 字段中查看。

## 字体

标题与大数字使用 **霞鹜文楷（LXGW WenKai）** 的子集字体，字体家族在页面中命名为 `Huaxia Serif`。字体以 SIL Open Font License 1.1 授权，许可全文见 `assets/fonts/OFL.txt`。

字体以 data URI 内嵌在 `assets/fonts/huaxia-serif.css` 中。这样无论通过 HTTP 访问，还是直接双击打开（`file://`），都能稳定显示同一套字形，不受浏览器对本地字体文件的跨域限制。`huaxia-serif.woff2` 是生成内嵌样式所用的子集文件，页面不会单独请求它。

当前 WOFF2 仅包含页面实际用到的字形。如果大幅增补文案，建议从 [LXGW WenKai](https://github.com/lxgw/LxgwWenKai) 重新取得完整字体并子集化，再替换 `huaxia-serif.css` 中的 data URI，以免生僻字回退到系统字体。
